# Nirvaan Lagishetty

**I build production systems around agents, not just agents themselves.**

I turn business workflows into software that can reason, use tools and execute work. I work across the agents, backend and infrastructure, from the first requirement through deployment and production debugging.

## My portfolio is a game

[nirvaan.biz](https://nirvaan.biz) is a retro CRT video game, not a portfolio website. Yukti, my guide character, walks you through four story routes in pixel-art scenes, with game subtitles and front-panel keys on the CRT cabinet. ## What I build

**Workflows that act:** research, interpret context and use APIs or browsers, with human approval for consequential actions.

**Systems that keep working:** durable execution, shared state and recovery when a worker, browser session or agent fails.

**Environments for agent work:** authorized, persistent project workspaces where agents can use development tools, run tests and continue across operator disconnects.

## Technical focus

**Agent systems:** orchestration, tool calling, RAG, context and memory, evaluation, MCP.

**Execution and backends:** Python, TypeScript, FastAPI, PostgreSQL, Temporal, Playwright.

**Deployment:** Docker, Linux, AWS (EC2, RDS, S3, SES v2, CloudWatch), Cloudflare Workers and CI/CD. My broader foundation includes machine learning and computer vision.
